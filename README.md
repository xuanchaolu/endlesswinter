# ❄️ 无尽冬日 · Endless Winter 3D

一款 **macOS 原生 App** 形式的 3D 冰原生存策略游戏。太阳变得黯淡，长冬吞没了世界 —— 你是一小群幸存者的领袖。守住那座熔炉，带领大家熬过无尽的寒冬。

无需网络、无需安装依赖，所有资源（含 3D 引擎）都打包进 App 内，完全离线可玩。

```
┌─────────────────────────────────────────────┐
│   原生窗口 (Objective-C + AppKit)            │
│   ┌───────────────────────────────────┐     │
│   │  WKWebView                        │     │
│   │  ├─ Three.js r128（本地打包）      │     │
│   │  ├─ world3d.js 雪原世界渲染        │     │
│   │  ├─ game.js    生存模拟 + UI       │     │
│   │  ├─ bgm.js     WebAudio 程序化配乐 │     │
│   │  └─ 存档桥接 → 应用支持目录         │     │
│   └───────────────────────────────────┘     │
└─────────────────────────────────────────────┘
```

## 🚀 构建与运行

```bash
./build.sh          # 编译 + 打包 + 生成图标 + 签名（会先跑无头逻辑测试）
open build/EndlessWinter.app
```

默认产出**通用二进制**（Apple Silicon + Intel 都能跑），最低支持 **macOS 11**。可用环境变量覆盖：

```bash
ARCHS=arm64 macOS_MIN=13.0 ./build.sh      # 只编本机架构 / 提高最低系统版本
```

长期使用可拖入应用程序目录：

```bash
cp -R build/EndlessWinter.app /Applications/
```

**环境要求**：macOS + Xcode 命令行工具（clang）、Python 3、Node.js（仅无头测试需要）。
Swift 工具链不参与构建，原生壳是纯 Objective-C + Cocoa/WebKit。

### 领地与建筑（24 类，可升级）

- **生存基础**：熔炉（10 级）、居民区（10 级，自动演化为木屋 → 石屋 → 洋楼 → 多层 → 小高层 → 高楼）、伐木场、煤矿、猎人小屋、铁矿场、采石场、仓库
- **民生**：农场、温室、菜园、医务室、研究所、学校、工坊
- **领地扩张**：木栅栏 → 石围墙 → **巨垒城墙（6 级）**，带城门、角楼与供暖岗楼
- **现代设施**：风力发电站（降耗煤）、地热钻井（提升供热）、无线电塔（降低发病率）、机场（物资空投）、码头、跨海大桥、灯塔
- **跨海工程**：码头 → 巨垒城墙满级后修建**跨海大桥**通往西侧冰海上的小岛 → 岛上建造**灯塔**（全局生产加成）

人口增长、建造升级、研究完成均实时反映在 3D 城市中：建筑随等级成长，居民小人白天外出工作、夜晚归家围炉，暴风雪时风雪横飞，炉火随火力设定明灭跳动，夜间窗户逐盏点亮。

## 🕹️ 操作

- **左键拖动** 旋转视角　**滚轮** 缩放　**右键拖动 / WASD / 方向键** 平移
- **点击建筑**（场景内或底部图标）选中并查看详情
- **空格** 暂停/继续　**1 / 2** 切换正常 / 三倍速度
- ⚙️ 政策与设置：口粮配给、静音、删除存档、**调试 / 测试面板**

存档自动保存于：`~/Library/Application Support/EndlessWinter/save.json`（并保留一份滚动备份 `save.json.prev`）。

## 🔨 开发

```bash
node tools/sim_test.js      # 无头逻辑回归测试（A~E 五段，构建前自动执行）
./build.sh                  # 构建脚本本身就是流程文档：测试 → 编译 → 打包 → 图标 → 签名
```

调试面板内置「🚀 一键满级」，可瞬间把所有建筑拉满、科技全点亮、资源加满，方便查看高阶建筑建模。

原生层支持自动测试通道：

```bash
build/EndlessWinter.app/Contents/MacOS/EndlessWinter --autotest
```

该参数会让游戏自动以当前存档开局、分步执行满级同步并输出结果到系统日志（`[AUTOTEST]` / `[SAVE]` 前缀），用于真机回归验证 3D 构建链路。

```
endless-winter/

    ├── style.css         # 冰原玻璃拟态界面
    └── js/
```

## 🧱 技术要点

- **原生壳极简**：`main.m` 一个文件搞定窗口、WKWebView、JSON 存档读写（原子写入 + 滚动备份校验回退）、JS→原生消息桥。
- **零外部资源**：所有纹理（木纹/砖纹/石纹/瓦片/立面/海浪）由 Canvas 程序化生成；配乐由 WebAudio 合成（A 小调和弦进行 + 五声音阶琶音 + 风声），不加载任何图片或音频文件。
- **程序化 3D 场景**：地形高度场、随等级重建的建筑模型、跨海大桥拱券、灯塔旋转光束、110 段城墙、居民小人四肢摆动动画，全部代码生成。
- **可测试性**：`game.js` 通过 `global.__G` 暴露内部函数，`sim_test.js` 用 stub 环境驱动完整游戏循环做回归断言；原生层 `--autotest` 提供真机端到端自检。
